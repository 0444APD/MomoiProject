# 대화 그래프

대화는 **선택 모듈**이다(`Optional/Dialogue`: 어셈블리 GameSystems.Dialogue · .Editor · .Tests). 쓰지 않는 프로젝트는 폴더째 지우면 되고, 코어는 대화를 참조하지 않는다. 화자·스탠딩은 대화 전용 **스탠딩 프로필**로, 게임의 캐릭터 데이터와 따로 관리한다.

대화는 노드 그래프로 만든다. `Game Systems → 대화 그래프` 창의 격자 배경에서 우클릭해 노드를 만들고, 점을 끌어 잇는다. 대사 한 줄이 노드 하나다. 연출 묶음은 `Game Systems → 연출 프리셋` 창에서 효과 노드로 만들고, 대화 그래프에서는 '연출 프리셋' 노드 하나로 쓴다.

## 두 종류의 선

**흐름**(흰 선, 둥근 점)은 대화가 어디로 가는지다. 시작 → 대사 → 선택지 → 조건 분기 → … 순서로 이어지고, 나가는 흐름 점 하나는 한 곳으로만 간다.

**신호**(분홍 선, 네모 점)는 연출이 언제 시작하는지다. 대사 노드는 진입·타이핑 완료·넘김 신호를 내고, 모든 효과는 시작·진행 지점(n%)·완료 신호를 낸다. 신호를 다른 효과의 '재생'에 이으면 체인이 된다(예: 배경 교체 90% → 스탠딩 등장, 스탠딩 등장 완료 → 흔들기). 신호 점 하나는 여러 곳으로 갈 수 있다. 진행 지점은 효과의 '진행 신호 지점' 목록에 퍼센트를 더하면 점이 생긴다.

대사 노드의 '대사 시작' 점에 신호를 이으면 그 신호가 올 때까지 글자가 나오지 않는다. 옛 시스템의 Prefix 잠금(연출 90% 진행 후 대사)은 이렇게 표현한다: 대사 진입 → 배경(진행 지점 90%) → 대사 시작.

## 노드

흐름 노드는 시작(시작 ID), 대사(화자·표정·원문·선택지·타이핑 속도·자동 넘김), 조건 분기(도전과제와 같은 조건 블록), 값 바꾸기(보상 블록: 값 더하기·아이템 지급 …), 신호 보내기(게임 코드로 `Signaled`), 다른 대화로(대화 ID·시작 ID), 끝이다. 선택지마다 흐름 점이 생기고, 선택지에 조건을 달면 맞을 때만 보인다(흐리게 보이기 선택 가능).

효과 노드는 두 가지다. **상태 효과**는 유지되는 화면 모습을 바꾼다: 배경, 배경 어둡게, 레터박스, 카메라, 배경 음악, 스탠딩 등장·퇴장·표정·이동·강조. **큐 효과**는 한 번 일어나고 끝난다: 흔들기, 번쩍임, 이펙트 생성, 효과음, 기다리기. 모든 효과에 시작 전 기다림, 진행 시간, 움직임 곡선, 진행 신호 지점, '다음 대사로 넘어가도 계속'이 있다. 캐릭터 칸을 비우면 현재 화자를 가리킨다(프리셋 안에서는 프리셋 노드가 정한 대상).

## 연출 프리셋

프리셋 창에서 '프리셋 시작' 노드의 신호로 효과들을 잇는다. '신호 내보내기' 노드를 두면 그 이름의 점이 대화 그래프의 프리셋 노드에 생긴다(예: 프리셋 안의 흔들기 시작 → 내보내기 "hit" → 대화에서 hit → 대사 시작). 프리셋 노드의 '완료'는 안에서 시작한 효과가 모두 끝났을 때 나온다.

## 스킵·되감기·저장

상태 효과는 시작하는 순간 논리 상태(`StageState`)를 끝 모습으로 바꾸고, 화면은 앞뒤 모습 사이를 그린다. 그래서 클릭(연출 중이면 체인 끝까지 마무리 후 대사 시작, 타이핑 중이면 글자 모두 보이기), 빨리 감기(`FastForward`), 다음 줄로 넘기기(이 줄에서 시작한 효과를 끝 모습으로 마무리, '계속' 효과 제외)가 모두 같은 결과 화면을 만든다. 지나온 줄마다 그때의 상태가 `History`에 남고, `Snapshot()`/`Resume()`으로 대화 중간 저장·불러오기를 한다.

## 코드

```csharp
var runner = DialogueRunner.FromDatabase(GameDatabase.Load());
runner.Session = GameSystemsRuntime.Session;   // 조건·값 바꾸기·대사 속 {player.gold}
runner.Stage = myStage;                         // IDialogueStage: 화면 그리기
runner.Signaled += signal => { if (signal == "openShop") OpenShop(); };
runner.Start("shopIntro");
// 매 프레임 runner.Tick(Time.unscaledDeltaTime), 클릭 runner.Advance(), 선택 runner.Choose(i)
```

대사 글자는 대사 키(`line.xxxxxxxxxx`, 자동·고정)로 텍스트 표를 찾고, 없으면 노드의 원문을 쓴다. 원문은 다국어 문장 틀 문법(`{player.gold}`, `{item:을}`, `[[burn]]`)을 그대로 쓴다. 대화 그래프를 시트로 내보내는 규격은 아직 정하지 않았다(대사 키·화자·원문·선택지·순서는 모두 데이터에 있다).

## 화면: 템플릿 프리팹

`Game Systems → 대화 UI 템플릿 만들기`는 `Assets/GameSystemsData/DialogueUI/`에 모든 기능이 연결된 한 벌을 만든다: `DialogueSystem.prefab`, `DialogueUI.uxml`·`DialogueUI.uss`(글상자·이름표·선택지·레터박스·번쩍임·검은 화면·툴팁), `DialogueChoice.uxml`(선택지 하나), 패널 설정·런타임 테마, 기본 모션 4개(열림·클릭 대기 깜빡임·선택지 나타남·고름), 흰 스프라이트. 프리팹을 씬에 놓고 `GetComponent<DialoguePlayer>().Play("대화 ID")`로 재생한다. 한글이 네모로 보이면 UI 오브젝트의 `DialogueUI > font`에 한글 TTF를 넣는다.

프리팹 구성: `DialoguePlayer`(실행기·입력·게임 시간 멈춤·신호 이벤트) › `Stage`(`DialogueStage`: 게임 카메라 앞에 배경 두 장·배경 어둡게·스탠딩·이펙트, 음악·효과음, 카메라 확대·이동·흔들기) · `UI`(`UIDocument` + `DialogueUI`).

**모양 바꾸기(프로젝트마다).** UXML·USS를 고친다. 코드는 요소를 **이름**으로만 찾으므로 이름만 지키면 배치·스프라이트·크기·클래스는 자유롭다. 이름이 다르면 `DialogueUI`의 이름 칸을 고친다. 인스펙터 아래 '요소 연결 확인'이 UXML에 이름 규격의 요소가 있는지(필수/선택) 바로 보여 준다. 필수는 `dialogue-root`·`dialogue-name`·`dialogue-text`·`dialogue-choices`이고, 나머지는 없으면 그 기능만 꺼진다. 여러 모양을 두려면 프리팹 변형(Prefab Variant)에서 UXML·모션만 바꾼다.

**애니메이션.** UI Toolkit 요소는 Animator·AnimationClip으로 움직이지 않는다. 대신 두 층을 쓴다. 나타나기·사라지기·색 변화처럼 '상태가 바뀌면 부드럽게'는 USS 전환(`transition`)과 루트의 상태 클래스(`dialogue--open`·`--staging`·`--typing`·`--waiting`·`--choosing`·`--narration`·`--speaker-<ID>`)로 USS 안에서 끝낸다(참조 연결 없음). 키프레임·반복·스프라이트 프레임 애니메이션은 **UI 모션** 에셋(`Create › Game Systems › 대화 › UI 모션`: 투명도·이동·크기·회전·색 곡선, 프레임 목록, 한 번/반복/왕복)을 만들어 `DialogueUI`의 모션 칸(순간 × 요소 이름 × 모션)에 넣는다. 순간은 열림·닫힘·줄 시작·화자 바뀜·클릭 대기·선택지 나타남·선택지 고름이다. 대화 그래프에서도 'UI 모션' 효과 노드로 원하는 순간에 어느 요소든 모션을 재생할 수 있다(체인에 들어간다).

**스탠딩.** 캐릭터의 '스탠딩 프리팹'이 비어 있으면 표정 스프라이트 두 장을 겹쳐 크로스페이드한다(`SpriteStandingView`, 높이는 `standingHeight`). 스파인은 프리팹에 `SpineStandingView`를 붙인다: 스파인 런타임을 직접 참조하지 않고 이름으로 찾아(`SkeletonAnimation`·`SkeletonGraphic`·`SkeletonMecanim`) 표정 ID와 같은 이름의 애니메이션을 재생하고(다르면 짝 목록), 밝기·투명도는 스켈레톤 색으로 준다. 다른 방식(Live2D 등)은 `StandingView`를 상속한다.

**그리기 방식.** 상태 효과는 효과 종류와 상관없이 '앞 모습 → 뒤 모습'에서 바뀐 값만 섞는다(배경 크로스페이드·검은 화면 경유, 어둡기, 레터박스, 카메라, 음악 교차, 스탠딩 등장·퇴장·위치·밝기·표정). 그래서 새 상태 효과를 더해도 화면 코드를 고칠 일이 거의 없다. 큐 효과는 흔들기(화면=카메라, 캐릭터=스탠딩), 번쩍임(UI 덮개), 이펙트(프리팹 생성, 진행 시간이 있으면 끝날 때 지움), 효과음, UI 모션이다.
## 캐릭터 프로필(스탠딩 프로필)

도감의 '캐릭터 프로필'에 스탠딩 목록(스탠딩 ID · 스프라이트)을 채운다. 그래프의 스탠딩 칸(스탠딩 등장·스탠딩 바꾸기·대사의 화자 스탠딩)은 캐릭터 칸이 정한 프로필의 스탠딩 ID를 드롭다운으로 고른다(캐릭터를 비우면 현재 화자라서 모든 프로필의 스탠딩이 프로필별로 묶여 나온다). 예외로 그 자리에만 다른 그림을 쓰려면 '예외 스프라이트'를 꽂는다(스탠딩 ID보다 우선, 스파인 스탠딩에는 쓸 수 없다).

## 프로젝트별 확장

**글 더하기(코드 없음).** 소속·직함·장소처럼 프로젝트마다 다른 글은 캐릭터 프로필 또는 대사 노드의 '추가 글'에 키와 글을 적고(대사가 우선), UXML에 `name="dialogue-extra-<키>"` Label을 둔다. 글이 비면 그 요소에 `dialogue-extra--empty`, 있으면 루트에 `dialogue--has-<키>`가 붙어 USS로 숨기거나 배치를 바꾼다. 번역은 `<캐릭터 ID>.<키>`·`<대사 키>.<키>` 텍스트가 있으면 그것을 쓴다. 템플릿에 소속(`affiliation`) 예시가 들어 있다.

**UI 동작 더하기.** `DialogueUIExtension`(또는 `IDialogueUIExtension`)을 상속한 컴포넌트를 대화 UI 오브젝트나 자식에 붙이면 열림·닫힘·대사(`DialogueLineInfo`: 대사 노드·프로필·이름·글·추가 글)·선택지 순간에 불린다. 요소는 `ui.Element("이름")`으로 찾는다.

**노드 더하기.** 효과는 `EffectNode`를, 흐름은 `CustomFlowNode`(Run이 다음 점 ID를 돌려준다)를 상속하고 `[GraphNode("이름", Category = …)]`를 붙이면 우클릭 메뉴에 나온다. 효과의 화면 그리기는 `CreatePlayer(stage, …)`에서 직접 만들고, 유지되는 값(날씨 등)은 `ApplyTo`에서 `state.Custom("키", true)`에 적으면 스킵·저장·되감기에 함께 따라간다.
## 클릭과 시간

한 번 클릭하면 그래프가 한 단위(대사 한 줄) 진행하고 다음 대사에서 멈춘다. 클릭은 연출 대기 중이면 막지 않는 효과를 끝 모습으로 보내고 대사를 시작하며, 타이핑 중이면 글을 다 보이고, 다 나왔으면 다음 대사로 간다.

**효과 시간 보장.** 효과마다 '진행 중 클릭 막기'가 있고 기본으로 켜져 있다(음악·효과음은 꺼짐). 켜진 효과가 도는 동안(시작 전 기다림 포함) 클릭과 선택은 무시된다. 끄면 그 효과는 클릭으로 끝 모습까지 건너뛴다. 연타로 두 줄씩 넘어가지 않도록 클릭을 받은 뒤 잠깐(0.12초) 다음 클릭을 무시한다.

**대사 넘기는 방식.** 대사 노드의 '넘기는 방식': 클릭 / 시간 진행(클릭 무시: 글이 다 나오고 머무는 시간 뒤 스스로 넘어가는, 애니메이션처럼 흐르는 대사) / 시간 진행(클릭 가능). 머무는 시간은 막는 효과가 끝난 뒤부터 잰다.

**자동 진행**(`DialoguePlayer.autoMode`, `autoDelay`): '클릭' 대사가 다 나오고 막는 효과가 끝나면 지연 뒤 클릭한 것으로 친다. **스킵**(`SkipToChoice`): 막는 효과까지 모두 끝 모습으로 보내며 다음 선택지가 뜰 때까지(또는 대화 끝까지) 건너뛴다.

## 미리보기

대화 그래프 창 위의 막대: '▶ 선택한 노드부터'(노드를 고르지 않으면 시작 노드부터), 일시정지, 시간 막대, 다음(클릭), 자동, 선택지까지 스킵, 정지. 연출 프리셋 창은 '▶ 프리셋 재생'. 실제 화면으로 보이도록 플레이 모드에서 씬의 `DialoguePlayer`로 재생한다(씬에 없으면 대화 UI 템플릿 프리팹을 잠시 꺼내 쓴다). 효과 노드를 골라 재생하면 그 효과 체인만 돈다.

시간 막대를 끌면 일시정지하고 그 시점으로 간다: 처음부터 다시 시작해 그 시점까지 클릭 없이 감으므로, 3초짜리 효과를 1.5초에 놓으면 50% 지점부터, 그 사이 늦게 시작된 효과도 각자의 진행도에서 이어진다. 트윈으로 그리는 모든 효과(배경·어둡게·스탠딩·카메라·흔들기·UI 모션 …)가 정확히 맞고, 스파인 애니메이션과 파티클은 자기 시간으로 흐르므로 이동한 시점에서 처음부터 다시 돈다. 클릭을 기다리는 대사를 지나 감으려면 '다음'으로 넘긴 뒤 이동한다(시간 이동은 클릭을 대신하지 않는다).

## 음성·오디오

음성과 오디오 채널·수명·종류별 옵션은 코어 오디오 기능으로 만들 예정이고, 대화는 그것을 쓴다. 지금의 배경 음악·효과음 효과는 대화 화면의 AudioSource를 직접 쓰는 임시 구현이다.

# 대화 그래프

대화는 노드 그래프로 만든다. `Game Systems → 대화 그래프` 창의 격자 배경에서 우클릭해 노드를 만들고, 점을 끌어 잇는다. 대사 한 줄이 노드 하나다. 연출 묶음은 `Game Systems → 연출 프리셋` 창에서 효과 노드로 만들고, 대화 그래프에서는 '연출 프리셋' 노드 하나로 쓴다.

## 두 종류의 선

**흐름**(흰 선, 둥근 점)은 대화가 어디로 가는지다. 시작 → 대사 → 선택지 → 조건 분기 → … 순서로 이어지고, 나가는 흐름 점 하나는 한 곳으로만 간다.

**신호**(분홍 선, 네모 점)는 연출이 언제 시작하는지다. 대사 노드는 진입·타이핑 완료·넘김 신호를 내고, 모든 효과는 시작·진행 지점(n%)·완료 신호를 낸다. 신호를 다른 효과의 '재생'에 이으면 체인이 된다(예: 배경 교체 90% → 스탠딩 등장, 스탠딩 등장 완료 → 흔들기). 신호 점 하나는 여러 곳으로 갈 수 있다. 진행 지점은 효과의 '진행 신호 지점' 목록에 퍼센트를 더하면 점이 생긴다.

대사 노드의 '대사 시작' 점에 신호를 이으면 그 신호가 올 때까지 글자가 나오지 않는다. 옛 시스템의 Prefix 잠금(연출 90% 진행 후 대사)은 이렇게 표현한다: 대사 진입 → 배경(진행 지점 90%) → 대사 시작.

## 노드

흐름 노드는 시작(시작 ID), 대사(화자·표정·원문·선택지·타이핑 속도·자동 넘김), 조건 분기(도전과제와 같은 조건 블록), 값 바꾸기(보상 블록: 값 더하기·아이템 지급 …), 신호 보내기(게임 코드로 `Signaled`), 다른 대화로(대화 ID·시작 ID), 끝이다. 선택지마다 흐름 점이 생기고, 선택지에 조건을 달면 맞을 때만 보인다(흐리게 보이기 선택 가능).

효과 노드는 두 가지다. **상태 효과**는 유지되는 화면 모습을 바꾼다: 배경, 배경 어둡게, 레터박스, 카메라, 배경 음악, 스탠딩 등장·퇴장·표정·이동·강조. **큐 효과**는 한 번 일어나고 끝난다: 흔들기, 번쩍임, 이펙트 생성, 효과음, 기다리기. 모든 효과에 시작 전 기다림, 진행 시간, 움직임 곡선, 진행 신호 지점, '다음 대사로 넘어가도 계속'이 있다. 캐릭터 칸을 비우면 현재 화자를 가리킨다(프리셋 안에서는 프리셋 노드가 정한 대상).

## 연출 프리셋

프리셋 창에서 '프리셋 시작' 노드의 신호로 효과들을 잇는다. '신호 내보내기' 노드를 두면 그 이름의 점이 대화 그래프의 프리셋 노드에 생긴다(예: 프리셋 안의 흔들기 시작 → 내보내기 "hit" → 대화에서 hit → 대사 시작). 프리셋 노드의 '완료'는 안에서 시작한 효과가 모두 끝났을 때 나온다.

## 스킵·되감기·저장

상태 효과는 시작하는 순간 논리 상태(`StageState`)를 끝 모습으로 바꾸고, 화면은 앞뒤 모습 사이를 그린다. 그래서 클릭(연출 중이면 체인 끝까지 마무리 후 대사 시작, 타이핑 중이면 글자 모두 보이기), 빨리 감기(`FastForward`), 다음 줄로 넘기기(이 줄에서 시작한 효과를 끝 모습으로 마무리, '계속' 효과 제외)가 모두 같은 결과 화면을 만든다. 지나온 줄마다 그때의 상태가 `History`에 남고, `Snapshot()`/`Resume()`으로 대화 중간 저장·불러오기를 한다.

## 코드

```csharp
var runner = DialogueRunner.FromDatabase(GameDatabase.Load());
runner.Session = GameSystemsRuntime.Session;   // 조건·값 바꾸기·대사 속 {player.gold}
runner.Stage = myStage;                         // IDialogueStage: 화면 그리기
runner.Signaled += signal => { if (signal == "openShop") OpenShop(); };
runner.Start("shopIntro");
// 매 프레임 runner.Tick(Time.unscaledDeltaTime), 클릭 runner.Advance(), 선택 runner.Choose(i)
```

대사 글자는 대사 키(`line.xxxxxxxxxx`, 자동·고정)로 텍스트 표를 찾고, 없으면 노드의 원문을 쓴다. 원문은 다국어 문장 틀 문법(`{player.gold}`, `{item:을}`, `[[burn]]`)을 그대로 쓴다. 대화 그래프를 시트로 내보내는 규격은 아직 정하지 않았다(대사 키·화자·원문·선택지·순서는 모두 데이터에 있다).

화면 그리기(`IDialogueStage`: 배경·스탠딩·카메라·글상자·선택지)의 기본 구현은 다음 단계에서 만든다.

# 결정 기록

개발자의 답과 승인으로 확정한 것을 쌓는 곳이다(GBible 진행 매뉴얼 `ProjectFlow.md` 2절). AI는 세션을 시작하면 이 파일부터 읽고, 여기 있는 것은 다시 묻지 않는다. 사람이 고쳐도 된다 — 고치면 AI가 다음에 읽고 따른다.

기획은 넘겨짚지 않는다: AI의 추천은 개발자가 답하거나 승인해야 확정이다. 답을 기다리는 추천·가안은 아래 '확인 기다리는 것'에 두고, 확정되면 결정 표로 옮긴다.

# 기획 명세서 — (게임 이름)

이 문서의 목적은 하나다: **AI가 아이디어를 제대로 흡수해서, 나중에 예외 없이 만들게 하는 것.** 기획을 대충 흡수한 채 시스템을 세웠다가 콘텐츠·레벨 디자인 단계에서 나온 기믹 때문에 시스템을 갈아엎는 일을 첫 단계에서 막는다. 진행 순서와 질문 규칙은 `ProjectFlow.md`(진행 매뉴얼)에 있다.

기믹의 범위는 네 게임(발라트로·와일드프로스트·매지크래프트·세피리아)이 보여 주는 정도로 본다(`GimmickCatalog.md`). 장르·화면·시간 방식·싱글/멀티는 자유다.

채우는 법

- **개발자는 가진 자료를 넘기고(0-1), AI가 자료로 이 문서를 채운 뒤 빈 곳·부딪히는 곳을 질문한다.** 개발자가 직접 채워 와도 된다. 어느 쪽이든 AI가 칸마다 출처를 붙인다: `(자료)` · `(질문 D-n)` · `(추천)`.
- **[필수]** 칸은 답이 있어야 AI가 시스템을 만들기 시작한다. **[선택]** 칸이 비면 AI가 추천값으로 정하고 결정 기록(`Docs/Decisions.md`)에 남긴 뒤 보여 준다.
- 모르면 비워 둔다. 틀린 답보다 빈칸이 낫다.
- **살아 있는 문서다.** 답이 칸을 바꾸면 AI가 이 문서를 고치고, 고친 칸 끝에 `(D-n)`을 붙인다.
- 글로 편하게 쓴다. 표 칸을 꼭 맞출 필요는 없다. 플랫폼은 PC(Steam)로 정해져 있다.
- 채운 예시: `PlanningSpec-CardDungeon.md`(구현 가이드 `BuildGuide`의 카드 던전).

## 1. 한 판의 흐름

- [필수] 시간: 턴제 / 실시간 / 섞임(어디가 실시간인지)
- [필수] 한 판이 무엇인가: 처음부터 끝까지의 순서(예: 시작 → 지도에서 길 고르기 → 전투 → 보상 → … → 보스 → 끝)
- [필수] 반복 단위: 턴·라운드·웨이브·방 … 그 안에서 플레이어가 하는 것
- [필수] 판이 끝나는 때: 승리 조건 / 패배 조건
- [필수] 판이 끝나도 남는 것: 해금·영구 강화·기록·화폐 … (없으면 "없음")
- [선택] 되돌리기(Undo): 마음대로 / 이번 턴 안에서만 / 없음
- [선택] 이어 하기: 끄고 켜면 하던 판을 이어서 / 처음부터 / 체크포인트에서(그 순간: 방 클리어 …)

> [!note]- 예시
> 덱빌딩: "시작 덱 10장 → 층마다 전투 1번 → 이기면 골드·카드 보상 → 3층마다 상점 → 10층 보스 → 끝. 반복 단위는 턴: 손패 5장 뽑기, 에너지 3으로 카드 내기, 턴 끝에 적 공격. 주인공 체력 0이면 패배, 보스를 잡으면 승리. 판이 끝나도 해금한 카드와 최고 층은 남는다. 이번 턴 안에서만 되돌리기."

## 4. 메인 룰과 기믹

### 4-1. 메인 룰 [필수]

놓인 조각들이 **언제, 어떤 순서로** 발동하나를 문장으로 적는다. 게임의 뼈대다.

> [!note]- 예시(네 게임)
> - 발라트로: "카드를 내면 족보를 정하고, 점수에 드는 카드를 왼쪽부터 하나씩 센다. 카드마다 그 카드에 반응하는 조커가 왼쪽부터 발동한다. 다음은 손에 든 카드, 마지막은 조커의 독립 효과를 왼쪽부터 낸다. 점수 = 칩 × 배수."
> - 와일드프로스트: "턴마다 적 보드 먼저, 각 보드에서 맨 앞 칸의 위·아래 → 가운데 칸 → 뒤 칸 순서(열 우선)로 카운터가 1씩 준다. 0이 되면 그 유닛이 맞은편 같은 줄 맨 앞을 공격하고 능력을 쓴 뒤 카운터가 돌아온다. 반응은 그 공격이 끝난 뒤에 발동한다."
> - 매지크래프트: "지팡이는 칸을 왼쪽부터 읽는다. 강화 주문은 다음 발사 주문에 붙고, 연계 주문은 왼쪽 주문이 끝나거나 맞힐 때 오른쪽 주문을 쏜다. 다 읽으면 쿨다운."
> - 세피리아: "가방에 놓으면 석판이 무늬대로 옆 칸 아티팩트의 레벨을 올린다. 레벨과 위치 제약으로 아티팩트가 켜지고, 같은 콤보 태그 수로 콤보 단계가 정해진다."

### 4-2. 메인 룰 구조 [필수 — 해당하는 것에 표시]

표시한 것은 AI가 메인 룰을 만들 때 자리를 미리 만든다. 나중에 나오면 메인 룰을 고쳐야 한다.

- [ ] 다른 것의 능력을 빌려 쓴다(복사·흉내 — Blueprint, Mimicry Cube)
- [ ] 놓인 순서·위치가 효과를 바꾼다(왼쪽부터 발동·옆 칸·같은 줄 — 순서가 열 우선이면 적기)
- [ ] 한 조각이 여러 칸을 차지한다
- [ ] 위치·조건에 따라 조각의 태그·속성이 바뀐다
- [ ] 자원을 다른 곳에서 내거나 여럿이 나눠 쓴다(빚 포함)
- [ ] 효과가 반복 발동한다(재발동·광란·추가 발동)
- [ ] 판정 규칙이 바뀐다(족보·승리 조건·대상 규칙)
- [ ] 반응을 발동이 끝난 뒤로 미룬다(맞으면 반격 — 때린 쪽의 효과가 다 끝난 뒤)

### 4-3. 기믹 갈래 [필수 — 쓰는 것에 표시]

갈래마다 만드는 법이 정해져 있다(`GimmickCatalog.md` 2절). 표시가 없는 갈래도 나중에 쓸 수 있다. 표시는 시스템층이 부품을 먼저 준비하는 데 쓴다.

- [ ] 다른 효과 고치기(받는 피해 −5·면역·두 배·대신 맞기·비용 0)
- [ ] 자리·순서(옆 칸·같은 줄·맞은편·자리 조건·다른 칸의 레벨 올리기)
- [ ] 반복·배율(한 번 더·두 배)
- [ ] 복사·흉내
- [ ] 변환(상태 효과 바꾸기·능력치 변환·진화)
- [ ] 확률·운(N% 확률·확률 2배)
- [ ] 규칙 바꾸기(판정·빚·죽음 막기·보스 능력 끄기)
- [ ] 쌓이는 값·카운터
- [ ] 세트·콤보(같은 태그 N개)
- [ ] 가진 동안 능력치
- [ ] 상태 효과(중첩·버프/디버프·반사·받는 피해 바꾸기)
- [ ] 보상·선택·경제(N개 중 고르기·다시 뽑기·할인·판매가)
- [ ] 판 구조·소환·시드(방 바꾸기·소환수·일일 도전)
- [ ] 대상: 자신 · 고른 대상 · 무작위 · 전체 · 조건으로 거른 대상 · 자리(옆·같은 줄·맞은편)

## 6. 부가 기능 [선택 — 켜면 붙는 것에 표시]

기믹이 아닌 장르 부품이다. 표시하면 GBible의 기능을 켜서 붙인다. 괄호 안은 같이 적을 것.

- [ ] 대화(다이얼로그): 어디서. 대화가 게임의 중심이면(비주얼 노벨) 읽은 대사 표시·이전 대사로 되감기·세이브 칸 수가 필요한지도(자동 진행·대사 로그는 있다)
- [ ] 겹치는 가방(인벤토리): 칸 수·겹치기·장비 칸·옮기는 법(끌어 놓기·두 번 누르기)
- [ ] 게임 안 달력·시각: 하루가 언제 넘어가나
- [ ] 현실 시간: 오프라인 보상·스태미나·일일 초기화 시각
- [ ] 시드 입력·일일 도전
- [ ] 칸 단위 맵(이동 범위·길찾기·시야): 크기·지형·이동 비용, 적 AI 한 줄
- [ ] 아주 큰 수(1e308을 넘음)
- [ ] 되감기("이번 턴 처음으로"·3회)
- [ ] 판 밖에서 하는 일(로비·뽑기·일일 임무)
- [ ] 세이브 슬롯 여러 개: 몇 개(수십 칸이면 적기)
- [ ] 키 바꾸기
- [ ] Steam(기본 켬): 클라우드 저장·리치 프레즌스. 리더보드가 필요하면 적기(GBible에 없다). 친구 초대는 0절 멀티(친구 방)

## 7. 진행·화면

- [필수] 씬(화면이 크게 바뀌는 단위) 목록과 바뀌는 때: 타이틀 → 지도 → 전투 → …
- [선택] 화면 목록(이름 · 보여 주는 것 · 플레이어가 누르는 것). 생김새는 적지 않는다.
- [선택] 연출이 끝날 때까지 입력을 막아야 하는 곳(피해 숫자·카드 이동 …)
- [선택] 효과 도중 고르기 창이 필요한 곳
- [선택] 조작과 카메라: 무엇으로 하나(마우스로 누르기·끌어 놓기·키보드·패드), 카메라(고정·따라감·플레이어가 움직임)

## 12. 개발자가 직접 하는 것 [필수]

로직·DB 항목(능력·패시브·상태 효과·도전과제 …)은 AI가 만든다. 추가·삭제·로직 변경은 AI에게 말로 요청한다. 개발자는 에디터에서 읽고 아래를 한다.

- [필수] **밸런싱 범위**: 에디터에서 바꾸고 싶은 숫자·고르는 값·참조(예: 적 체력 · 카드 비용 · 보상으로 줄 아이템 · 드롭 확률). 비우면 "바꿀 만한 숫자는 모두".
- [필수] **레벨 배치**: 무엇을 배치하나(맵·적·보상·사건) · 어디에서(Unity 씬·타일맵 / DB의 레벨 항목) · 한 레벨의 단위(층·방·스테이지·웨이브). 레벨에만 있는 특수 칸·사건(함정·스위치·무작위 방)이 있으면 적는다. 없으면 "없음".
- [선택] **대사**: 다이얼로그 그래프로 쓰나 · 대사가 규칙 값(호감도·플래그·자원)을 바꾸나.
- [선택] **에셋**: 그림·소리·글꼴을 누가 언제 넣나. 비우면 "AI가 임시 자리를 만들고 목록을 주면 개발자가 가져온다".

# 기획 명세서 — (게임 이름)

이 문서 하나를 채우면 AI가 게임의 **시스템층**(규칙·한 판의 흐름·아이템·몬스터·스킬을 쉽게 더할 수 있는 중간층·성장 곡선)을 만든다. 개별 카드·몬스터·수치(레벨 디자인)는 여기 적지 않는다 — 대표 예 두세 개면 된다.

채우는 법

- **[필수]** 칸이 비면 AI가 묻는다. **[선택]** 칸이 비면 AI가 장르에 맞는 추천값으로 정하고 무엇으로 정했는지 알려 준다.
- 모르면 비워 둔다. 틀린 답보다 빈칸이 낫다(AI가 추천값과 이유를 붙여 한 번에 묻는다).
- 글로 편하게 쓴다. 표 칸을 꼭 맞출 필요는 없다.
- 플랫폼은 PC(Steam)로 정해져 있다.
- 채운 예시: `PlanningSpec-CardDungeon.md`(가이드의 카드 던전).

## 1. 한 판의 흐름

- [필수] 시간: 턴제 / 실시간 / 섞임(어디가 실시간인지)
- [필수] 한 판이 무엇인가: 처음부터 끝까지의 순서(예: 시작 → 지도에서 길 고르기 → 전투 → 보상 → … → 보스 → 끝)
- [필수] 반복 단위: 턴·라운드·웨이브·하루 … 그 안에서 플레이어가 하는 것
- [필수] 판이 끝나는 때: 승리 조건 / 패배 조건
- [필수] 판이 끝나도 남는 것: 해금·영구 강화·기록·화폐 … (없으면 "없음")
- [선택] 되돌리기(Undo): 마음대로 / 이번 턴 안에서만 / 없음
- [선택] 이어 하기: 끄고 켜면 하던 판을 이어서 / 처음부터 / 체크포인트에서

> [!note]- 예시
> 덱빌딩: "시작 덱 10장 → 층마다 전투 1번 → 이기면 골드·카드 보상 → 3층마다 상점 → 10층 보스 → 끝. 반복 단위는 턴: 손패 5장 뽑기, 에너지 3으로 카드 내기, 턴 끝에 적 공격. 주인공 체력 0이면 패배, 보스를 잡으면 승리. 판이 끝나도 해금한 카드와 최고 층은 남는다. 이번 턴 안에서만 되돌리기."

## 3. 핵심 동사

게임 규칙의 기본 동작이다. 나중에 오는 이상한 효과(반사·면역·두 배·대신 맞기)는 모두 이 동사를 고치는 것으로 만들어진다.

| 동사 | 무엇이 바뀌나 | 효과가 고칠 수 있어야 하나(예: "피해 −5", "막기") |
|---|---|---|
| (예: 피해) | (대상 체력, 방어도 먼저) | (예) |
| (예: 카드 내기) | (에너지 −비용, 손패 → 버린 더미) | (예: "이번 턴 비용 0") |
|  |  |  |

- [필수] 위 표. 생각나는 것만 적어도 된다(피해·회복·죽음·사용·비용·뽑기·이동·획득 … 중 이 게임에 있는 것).

- [필수] 언제

  - [ ] 지속(N턴 동안·N초 동안 — 버프·디버프·중첩)

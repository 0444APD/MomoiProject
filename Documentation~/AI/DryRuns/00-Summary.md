# 6장르 시험 — 요약

기획 명세서 양식 + GBible 문서·관례만 받은 AI가 장르마다 이상한 기믹이 든 게임의 시스템층을 만든다고 놓고, 질문·쪼개기·빈틈을 본 시험이다(2026-10-04). 장르마다의 명세서·질문·시스템 목록·쪼개기·빈틈은 같은 폴더의 1~6번 파일, 고친 결과는 각 파일 끝의 "보강 뒤" 절.

| 장르 | 질문 | 문법 밖(시험 때) | 문법 밖(보강 뒤) | 하루 판단(시험 때) |
|---|---|---|---|---|
| 1 턴제 전술 SRPG | 12 | 0 | 0 | 시스템층은 됨, 화면까지는 격자·맵 입력 흐름이 없어 어려움 → `Grid`·DB › 화면이 생김 |
| 2 실시간 액션 로그라이트 | 12 | 3 | 0 | 규칙층·UI는 됨, 전투 화면 쪽(조작·AI·히트박스)은 범위 밖 |
| 3 서바이버라이크 | 7 | 3 | 0 | 조건부(무기 동작 종류를 줄이면) |
| 4 수집형 RPG | 4 | 3 | 0 | 시스템층은 됨, 화면은 빠듯 → 현실 시각·천장·경로 [키]가 생김 |
| 5 방치형 | 3 | 2 | 0 | 됨 |
| 6 농장 생활 시뮬 | 6 | 1 | 0 | 규칙·DB·화면은 됨, 2D 월드(이동·길찾기·낚시)는 사람이 씬을 만든다 |

- 질문은 모두 20개 이하였다.
- 문법 밖이 0이 된 이유: 현실 시각(`Game.Now`), 큰 수(`BigNumber`), 그리고 **판정 보고 행동**(물리·충돌·미니게임은 화면이 판정하고 결과를 행동으로 — 관례 3절)을 문법 안으로 정했다. 같은 세션 안 되감기는 `UndoTo`.
- 남은 공통 범위 밖: 실시간 게임의 화면 쪽(조작·물리·적 이동·오브젝트 풀)과 씬·프리팹·그림은 사람(또는 프로젝트 코드)이 만든다. GBible은 그 결과를 받는 규칙·데이터·UI를 맡는다.

## 보강한 것(라이브러리)

시간·저장: `Game.Now`·`Day`·`Week` · 판 저장 N초마다·이벤트를 받을 때 · 판·프로필 저장 어긋남 고침 · `Saving`·`RunLoaded`·`Stopping` · `HistoryMark`·`UndoTo` · Undo 보관 기본 200.
규칙 부품: 필드 경로 `name[키]` · 상태 효과(이벤트·걸 때 길이·줄이기·주기·검사 조건·아이콘·숨김, 그 이벤트에 건 것 세지 않기) · 기본 대상 Block 5개 · DB › 패시브 · 의도 고치기 값 틀 · 가중치 표 밸런스 무게(천장) · 원본 ID → 딕셔너리 개수 · `NewIds` · 행동 안 구독자 실패 → 행동 취소.
화면: `GameView.Play` · `GameScreen.Tick` · 고르기 창 설명·고르는 동안 시간 멈춤.
수학: `Grid`(격자) · `BigNumber` · `BalanceSum`·`BalanceCount`.

## 보류한 것(다음 후보)

여러 장르에서 나온 순서: 게임 안 달력 선택 기능(농장·RPG) · DB 격자 맵·Tilemap 굽기 · 일일·주기 임무 선택 기능(수집형) · 인벤토리 고정 칸·칸 정보 · ViewList 오브젝트 풀 · 슬롯을 넘는 저장 · 행동 안 예측(dry-run 가로채기) · `Game.Find` id 색인(성능) · 가중치 표 줄 조건의 '이 줄의 항목' · 텍스트 틀 숫자·시간 서식 · 자동 진행(Autoplay).

작은 것: 예시 게임(Tools/GuideExample)의 `BuyCard`가 화면에서 가격을 받는 것(규칙이 가격을 읽게 — 가이드 06장 상점과 함께) · DB 필드 고르기 창에서 `[키]` 경로 고르기 · `Grid.Path` 대각선의 모서리 지나기 막기 · 고르기 창을 같은 ID(momoi.choice)의 DB 항목으로 바꿀 때 뒤로로 닫기 기본값 · `BigNumber.Parse`의 한국어 단위.

# 4게임 기믹 시험 — 요약

기믹 범위를 네 게임(발라트로·와일드프로스트·매지크래프트·세피리아)으로 잡은 뒤(기믹 목록 `GimmickCatalog.md`), 그 게임의 실제 조각 목록과 섞은 장르로 같은 시험을 했다(2026-10-05). 7~12번 파일, 고친 결과는 각 파일 끝의 "보강 뒤" 절.

## 보강한 것(라이브러리)

패시브: 발동 더(`rules`) · 일치 필드 글자 목록 · 원본에서 읽기(`matchVia`) · 레벨 0 꺼짐 · 침묵 · 보정 조건(`modifierWhen`) · 보정 줄마다 받을 대상 · 받을 대상 `[]`(모두) · 여럿일 때(`stacking`) · 주기(`pulse`) · 스위치 패시브 · 빌려 쓰기의 가진 쪽 필드.
의도·상태 효과: 효과 배율(`PowerIntent` → `TriggerContext.Power`) · 상태 효과 걸기의 최대 중첩·주기·건 쪽(`by`) · 걸린 쪽의 패시브를 끔 · 대상 '상태 효과로 거르기'.
비용·값: `Game.TryPay` · 비용 의도 `forId`·`userId` · 값 틀 `{user:경로}`·`{event:경로}`·`{data:키.경로}`·`{count:키.경로}` · 이벤트 쏘기 값에 틀 · 조건 '사용자 필드 검사' · 숫자 참조가 보정을 읽음.
자리: 방향 같은 열 맨 앞·맨 뒤 · 자리 같은 열 맨 앞·같은 열에 혼자 · 기준 '없음' · `players[].칸`(기준이 든 목록).

# 04. 모니터로 지켜보기

메뉴 **MomoiProject › 모니터**. 플레이 중인 게임을 들여다본다.

| 탭 | 무엇을 보나 |
|---|---|
| 타임라인 | 무엇이 왜 바뀌었나 — 행동 → 이벤트 → 효과 → 값 변화가 원인과 함께 한 줄씩 |
| 데이터 | 지금 플레이어 데이터(판·프로필)의 값. 고치면 개발용 행동으로 남고 Undo된다 |
| 도전과제·로그 | 진행·달성, 모은 기록 |
| 이벤트 | 이벤트를 골라 값을 채워 쏴 보기(이벤트 호출) |
| 행동 | 지금까지의 행동과 Undo |
| 명령 | 기다리는 선택에 답하기 · **테스트 상황** 저장·불러오기 · 테스트 명령 버튼 |

## 흐름

1. 테스트 씬(05장)이나 게임 씬을 플레이한다.
2. 이상한 값이 보이면 **타임라인**에서 그 값이 바뀐 줄을 찾는다 — 어느 행동·효과가 바꿨는지 보인다.
3. **데이터** 탭에서 값을 바로 고쳐 본다(Undo 된다). 숫자를 계속 쓸 거면 DB에서 바꾼다.
4. 버그면 **명령 › 테스트 상황 › 지금 저장**으로 상황을 남기고 버그 보고(02장)에 그 이름을 적는다.

> [!note]- 저널(경고·오류)
> 타임라인에는 규칙이 남긴 경고(행동 직전 이벤트 사슬 끊김, 못 찾은 대상 …)도 보인다. 버그 보고에 그 줄을 그대로 붙이면 AI가 원인을 빨리 찾는다.

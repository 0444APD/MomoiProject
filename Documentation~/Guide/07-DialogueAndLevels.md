# 07. 대사·레벨 배치

대사와 레벨 배치는 **개발자가 직접** 한다. AI는 그것이 규칙과 이어지도록 데이터 모양과 도구를 만든다.

## 대사 — 다이얼로그 그래프

1. 메뉴 **MomoiProject › 다이얼로그 시스템 › 그래프**에서 새 다이얼로그를 만든다(개발자가 만드는 종류라 추가·삭제가 열려 있다). 장소·스탠딩 프로필은 DB 사이드바 › 다이얼로그 시스템, 연출 프리셋은 메뉴 › 다이얼로그 시스템 › 연출 프리셋.
2. 그래프 창에서 시작 → 대사 → 선택지 → 분기 노드를 잇는다.
3. **규칙과 잇는 노드**: '값 바꾸기'(호감도 +1, 플래그 켜기), '신호 보내기'(게임 코드가 받는다), 조건 분기(플레이어 데이터를 본다). 어떤 값·신호를 쓸지는 AI가 목록으로 알려 준다.

> [!note]- 지금 다이얼로그의 동작(주의)
> 대사 진행은 Undo 밖이다(되감기 없음), 선택지 조건은 선택지가 뜰 때 한 번 본다, '신호 보내기' 뒤 대화는 기다리지 않고 바로 다음 노드로 간다(상점을 열고 기다리려면 신호 다음을 '끝'으로), 읽은 대사 기록은 없다. 필요하면 AI에게 말한다. 자세한 것은 매뉴얼 [24장](../Manual/24-Dialogue.md) 8절.

## 레벨 배치

프로젝트마다 레벨의 모양이 다르다. AI가 단계 1(시스템층)에서 자리를 만들고, 레벨 디자인을 요청하면 배치 도구와 함께 알려 준다. 보통 둘 중 하나다.

- **씬에서 배치**: 맵·타일·스폰 지점·이벤트 칸을 Unity 씬에 놓는다(AI가 만든 컴포넌트를 오브젝트에 붙인다).
- **DB에서 배치**: 레벨 종류(층·웨이브·방)의 항목에서 적·보상을 드롭다운으로 고르고 줄을 더한다.

배치한 레벨은 테스트 씬(05장)에서 바로 돌려 본다. 배치 중에 "이 칸에서는 규칙이 달라졌으면" 같은 것이 생기면 AI에게 변경 요청(02장).

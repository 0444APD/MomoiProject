# 01. 시작하기

## 흐름

1. **Unity 프로젝트를 만들고 GBible 패키지를 넣는다.** 처음 열면 **시작 설정** 창이 뜬다. 게임 이름(Product Name)과 언어만 고르고 **적용**을 누른다. 코드 폴더·시작 파일·DB가 생긴다. 쓸 기능(다이얼로그·인벤토리·입력·Steam)과 Undo 방식은 고르지 않는다 — AI가 첫 단계의 기획 질문으로 정해 넣는다.
2. **Claude Code 파일이 저절로 생긴다**: 프로젝트 폴더의 `CLAUDE.md`, 스킬 `/think-momoi`, 컴파일 검사 훅, `Docs/PlanningSpec.md`(기획 명세서 양식), `Docs/Decisions.md`(결정 기록).
3. **자료를 넘긴다**: 기획서·콘텐츠 목록(시트)·레퍼런스·그림을 `Docs/Source/`에 넣는다. 효과 문장이 많을수록 좋다(기믹의 폭은 콘텐츠가 정한다). 수치는 비어도 된다.
4. **Claude Code를 프로젝트 폴더에서 열고 말한다**: "/think-momoi `Docs/Source`의 자료로 새 프로젝트를 시작해 줘."
5. AI가 자료를 끝까지 읽고 기획 명세서를 채운 뒤 **질문을 한 번에** 보낸다. 번호로 답한다(02장).

> [!note]- 시작 설정에서 고른 것을 나중에 바꾸려면
> 시작 설정 창은 메뉴 `MomoiProject › 개발 › 시작 설정`으로 다시 연다(이미 있는 파일은 덮지 않는다). 쓸 기능은 AI가 기획대로 켜고, DB 사이드바의 '기능 활성화'에서도 켜고 끈다. 판 저장·Undo·고정 틱 같은 설정은 DB › 시작 파일 › Bootstrap. 무엇을 바꿔야 할지 모르겠으면 AI에게 "판 저장을 체크포인트마다로 바꾸고 싶어"처럼 말하면 된다.

> [!note]- Claude Code 파일은 저절로 맞춰진다
> 에디터를 열 때 패키지가 바뀌었으면 `CLAUDE.md`의 표시한 칸·스킬·훅을 다시 맞춘다. 칸 밖에 직접 적은 것과 `Docs/`의 두 파일은 그대로 둔다. 맞추지 않으려면 메뉴 `MomoiProject › 개발 › Claude Code 파일 맞추지 않기`, 지금 맞추려면 `… › Claude Code 파일 지금 맞추기`.

> [!note]- 기획 명세서를 직접 채워 와도 된다
> `Docs/PlanningSpec.md` 양식을 열어 아는 칸만 채워도 된다. 비어 있는 칸은 AI가 추천을 붙여 묻는다 — 넘겨짚지 않고, 답하거나 추천을 승인해야 확정이다. 칸마다 AI가 출처를 붙인다(`(자료)` · `(답 D-n)` · `(추천 승인 D-n)`). 답이 바뀌면 AI가 명세서를 고친다.

> [!note]- 첫 단계(흡수)가 길어도 괜찮다
> 첫 단계에서 AI는 "이런 것도 나올 수 있나요?"를 많이 묻는다(소환·복제, 효과 도중 고르기, 시간 되감기, 레벨의 특수 칸 …). 나중에 레벨 디자인 단계에서 기상천외한 기믹이 나와 시스템을 갈아엎는 일을 지금 막기 위해서다. 아직 생각하지 않은 것은 "아마 아니오"나 "추천대로"로 답해도 된다 — 그 답이 확정이 된다. 답하지 않은 칸은 확정되지 않고 AI가 다시 확인을 청한다.

# 01. 시작하기

## 흐름

1. **Unity 프로젝트를 만들고 GBible 패키지를 넣는다.** 처음 열면 **시작 설정** 창이 뜬다. 게임 이름·턴제/실시간·쓸 기능(다이얼로그·인벤토리·Steam …)을 고르고 만들기를 누른다.
2. **Claude Code 파일이 저절로 생긴다**: 프로젝트 폴더의 `CLAUDE.md`, 스킬 `/think-momoi`, 컴파일 검사 훅, `Docs/PlanningSpec.md`(기획 명세서 양식), `Docs/Decisions.md`(결정 기록).
3. **자료를 넘긴다**: 기획서·콘텐츠 목록(시트)·레퍼런스·그림을 `Docs/Source/`에 넣는다. 효과 문장이 많을수록 좋다(기믹의 폭은 콘텐츠가 정한다). 수치는 비어도 된다.
4. **Claude Code를 프로젝트 폴더에서 열고 말한다**: "/think-momoi `Docs/Source`의 자료로 새 프로젝트를 시작해 줘."
5. AI가 자료를 끝까지 읽고 기획 명세서를 채운 뒤 **질문을 한 번에** 보낸다. 번호로 답한다(02장).

> [!note]- 시작 설정에서 고른 것을 나중에 바꾸려면
> 쓸 기능은 DB 사이드바의 '기능 활성화'에서 켜고 끈다. 판 저장·Undo·고정 틱 같은 설정은 DB › 시작 파일 › Bootstrap. 무엇을 바꿔야 할지 모르겠으면 AI에게 "판 저장을 체크포인트마다로 바꾸고 싶어"처럼 말하면 된다.

> [!note]- 기획 명세서를 직접 채워 와도 된다
> `Docs/PlanningSpec.md` 양식을 열어 아는 칸만 채워도 된다. [필수] 칸이 비면 AI가 묻는다. 칸마다 AI가 출처를 붙인다(`(자료)` · `(질문 D-n)` · `(추천)`). 답이 바뀌면 AI가 명세서를 고친다.

> [!note]- 첫 단계(흡수)가 길어도 괜찮다
> 첫 단계에서 AI는 "이런 것도 나올 수 있나요?"를 많이 묻는다(소환·복제, 효과 도중 고르기, 시간 되감기, 레벨의 특수 칸 …). 나중에 레벨 디자인 단계에서 기상천외한 기믹이 나와 시스템을 갈아엎는 일을 지금 막기 위해서다. 아직 생각하지 않은 것은 "아마 아니오"나 "모르겠다"로 답해도 된다 — AI가 기록하고 추천값으로 간다.

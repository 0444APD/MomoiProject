# 운영 가이드

GBible(Momoi Project)로 게임을 만들 때 **개발자(사람)가 하는 일**을 순서대로 안내한다. 코드는 AI(Claude Code)가 쓰고, GBible은 AI가 만든 모든 것을 개발자가 에디터에서 **읽고 · 밸런싱하고 · 테스트하는** 도구다.

| 누가 | 하는 일 |
|---|---|
| **AI** | 로직 · 데이터 구조 · DB 항목 · 화면 · 테스트 도구를 코드로 만든다. 질문하고, 정한 것을 결정 기록에 남긴다 |
| **개발자** | 자료를 넘기고 질문에 답한다 · DB에서 읽고 값을 바꾼다 · 테스트 씬에서 시험한다 · 다이얼로그 그래프를 만들고 레벨을 배치한다 · 에셋을 가져온다 · AI가 만든 DB 항목을 보고 적용(Ctrl+S)한다 |

개발자가 에디터에서 하지 않는 것: 로직 만들기, 로직 쪽 DB 항목(액티브 효과·패시브 효과·상태 효과·도전과제 …) 추가·삭제. 그런 것은 AI에게 말로 요청한다("이 유물을 없애 줘", "적이 죽을 때 폭발하게 해 줘").

> [!note]- AI가 보는 문서는 따로 있다
> AI는 `Documentation~/AI/`(진행 매뉴얼·관례·참조·기믹 목록·구현 가이드)와 `Documentation~/Manual/`(기능별 매뉴얼)을 읽고 일한다. 이 가이드는 사람용이라 코드가 없다. 기능이 궁금하면 매뉴얼의 해당 장을 열어도 된다.

## 하루의 흐름(예)

1. Claude Code에 오늘 할 일을 말한다(`/think-momoi` — "콘텐츠 시트 2번 묶음 넣어 줘").
2. AI가 질문하면 답한다. AI가 일을 끝내면 끝에 **개발자가 할 일**을 적어 준다.
3. DB 창에서 '적용 전' 항목을 읽어 보고 Ctrl+S.
4. 테스트 씬을 플레이해 테스트 패널(F1)로 시험하고, 숫자를 DB에서 맞춘다.
5. 이상하면 버그 보고 양식(02장)으로 AI에게 말한다.

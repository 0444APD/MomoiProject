# 08. 출시

AI에게 "출시 준비 단계로 가자"고 하면 체크리스트를 하나씩 확인하고 결정 기록에 남긴다. 개발자가 직접 할 것은 이것이다.

## 체크리스트

- [ ] **Steam**: Steamworks에서 앱을 만들고 App ID를 DB › 개발 › Steam에 넣는다. 도전과제 API Name·통계 이름을 Steamworks에 게시한다. Steam Cloud는 Auto-Cloud 경로(매뉴얼 34장).
- [ ] **출시됨**: 메뉴 `MomoiProject → 개발 → 출시됨 (저장 호환 유지)`. 이후로는 데이터 구조가 바뀌어도 플레이어 저장을 지우지 않는다.
- [ ] **에셋**: 에셋 관리 › 넣을 것이 모두 ✓. 안 쓰는 것을 정리했다.
- [ ] **검증**: DB "검증 통과", 콘솔 오류 0.
- [ ] **글**: 출시 언어마다 빠진 텍스트 없음.
- [ ] **빌드**: 출시 빌드(Development Build 끔)로 한 판을 끝까지. 테스트 패널·개발 명령이 안 보이는지.

> [!note]- 리더보드·친구 초대
> GBible에는 아직 없다. 필요하면 AI에게 말한다(매뉴얼 34장 4절).

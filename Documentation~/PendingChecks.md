# 직접 확인할 것 (Momoi Project)

GBible의 동작(규칙·저장·에디터 흐름·멀티의 주고받기)은 코드 흐름 점검과 오프라인 시험으로 확인했다(2026-10-06). 여기에는 **사람이 보고 들어야 알 수 있는 것**과 **Unity 에디터 밖(빌드·Steam·다른 컴퓨터)이 있어야 하는 것**만 남긴다. 할 일 → 보이면 정상. 이상하면 줄 이름과 함께 알려 주면 된다. 확인된 줄은 지운다.

## 1. 눈·귀로 볼 것 (에디터, 첫 게임 프로젝트가 생기면)

- **게임 화면(UI Toolkit, 매뉴얼 35장)**: 기본 고르기 창(어두운 덮개 + 후보 버튼)·설정 화면(토글·슬라이더·드롭다운)·슬롯 화면·일시정지 메뉴·확인 팝업의 모양, 실패 알림이 화면 아래에 잠깐 뜨는 모양, 1920×1080 기준으로 크기가 맞는지.
  - 고르기 창이 열리는 순간 빈 창이 깜빡이지 않는다.
  - 설정 화면에서 언어를 바꾸면 열려 있는 기본 화면(설정·일시정지)의 제목·버튼 글자도 바로 바뀐다.
  - 슬롯 화면: 지금 슬롯의 플레이 시간이 저장 뒤에 흐른 만큼 늘어 보이고, 저장한 슬롯은 저장한 때(날짜·시각)가 보인다.
- **한글 글꼴**: DB › 개발 › 화면 설정 › 글꼴이 비어 있으면 DB에 경고가 뜨고 한글이 □로 보일 수 있다. 한글 TTF를 넣으면 경고가 사라지고 모든 화면(기본 화면 포함)에 쓰인다.
- **연출 체감**: 피해 숫자·카드 이동 같은 연출이 차례로 보이고, 속도를 올리면 빨라지고, 건너뛰기를 누르면 남은 것이 빠르게 끝난다. 씬 흐름으로 씬이 바뀌면 페이드인 동안에도 새 씬의 값 표시가 비어 있지 않다.
- **소리**: 실제 소리, 음량 설정을 바꿨을 때의 크기(슬라이더를 끄는 동안 바로 바뀐다), 배경음 페이드 체감.
- **다이얼로그**(선택 기능을 켠 뒤): 글상자 블러(뒤의 게임 화면까지 흐려지는지), 모션, 로그 창, 장소 표시, 창 모드 스탠딩, 이미지 창, 한글 폰트(`DialogueUI.font`에 TTF), 그래프 창의 마우스 조작(범위 선택·그룹 상자 크기), 미리보기 막대(재생·시간 이동).
- **스프라이트 맞춤 창**(매뉴얼 27장): 규격 그룹을 쓰는 스프라이트 필드에 원본을 넣으면 맞춤 창이 열리고, 중심·배율을 옮기면 미리보기가 따라가고, 구운 이미지가 의도한 모양으로 잘린다.
- **키 바꾸기**(선택 기능 '입력', 게임 코드가 `GameInput.Use`를 부를 때): 실제 키·패드를 눌러 바꾸기, 같은 맵의 다른 키와 겹치면 겹침 표시, Esc로 취소, 다음 실행에도 남는지.
- **멀티 체감**(테스트 씬 › 패널 '멀티' › 시험 모드): 지연 막대를 0.4로 올리면 결과가 눈에 띄게 늦게 오는데 화면이 이상하지 않은지. 리플레이를 틀면 화면·연출이 처음부터 그대로 다시 보이는지.
- **실시간 위치**(`NetTransformSync`): 두 프로그램에서 움직이는 오브젝트가 상대 화면에서 부드럽게 따라오는지.
- **스파인 스탠딩**: 이 프로젝트에 스파인이 없어 한 번도 실행하지 못했다(스파인을 쓰는 프로젝트에서).

## 2. 빌드·Steam·다른 컴퓨터

- **Steam(에디터)**: 이 PC의 Steam을 켜고 로그인한 채 아무 씬에서 플레이 → 콘솔에 "[MomoiProject] Steam에 붙었습니다: (내 Steam 이름) · App ID 480", Steam 친구 목록에서 내 상태가 Spacewar 하는 중. Steam을 끈 채 플레이하면 "Steam에 붙지 못해 Steam 없이 시작합니다" 경고 하나만.
- **Steam 오버레이(빌드)**: Windows 개발 빌드를 Steam을 켠 채 실행 → Shift+Tab으로 오버레이가 뜨고, 열면 게임이 멈추고 닫으면 이어진다(에디터에서는 원래 뜨지 않는다). 빌드에서도 안 뜨면 Steam 라이브러리 › 게임 추가 › 비 Steam 게임 추가로 그 exe를 넣고 Steam에서 실행해 본다.
- **빌드(PC, IL2CPP)**: 판 저장·이어 하기, 플레이어 데이터 변경 기록·Undo, 이벤트 기록 문장이 빌드에서도 돈다. 설정의 전체 화면·해상도가 빌드에서 바뀐다. 출시 빌드 exe를 Steam 밖에서 바로 켜면 Steam으로 다시 켜진다(자기 App ID가 생긴 뒤).
- **서버 빌드**: Build Profiles › Dedicated Server(Windows 또는 Linux) 빌드를 `-batchmode -nographics -momoi-server 7777`로 켜도 로그에 화면(UI) 관련 오류가 없다.
- **직접 접속(빌드 + 에디터, 한 컴퓨터)**: 빌드를 `-momoi-host`로 켜고, 에디터 테스트 패널 '멀티'에서 주소 `127.0.0.1:7777` › 방 참가 → 명단 2명, 한쪽의 행동이 다른 쪽에 보인다. 처음 열 때 Windows 방화벽 창이 뜨면 허용. 방장 빌드에서 '나가기' → 에디터에 바로 "서버 연결이 끝났습니다: 방이 닫혔습니다."(다시 접속하지 않음). 방장 빌드를 작업 관리자로 강제로 끄면 다시 접속을 6번(약 45초) 시도한 뒤 끝난다.
- **매칭큐(빌드 + 에디터)**: 빌드 하나에서 패널 '매칭큐 서버', 에디터와 다른 빌드에서 '매칭 찾기' → 로비(점수 1000) → 줄 서기 → 수락 → 방에 들어간다. `%USERPROFILE%\AppData\LocalLow\DefaultCompany\UnitySystemProject\MomoiProject\server\accounts`에 계정 파일.
- **다른 컴퓨터**: 위 직접 접속을 같은 가상 랜(Tailscale 등)의 IP로.
- **잠깐 끊긴 네트워크(두 컴퓨터)**: 방에 들어간 클라이언트 컴퓨터의 와이파이(랜선)를 10초쯤 끊었다 다시 켜면, 클라이언트가 스스로 다시 접속해 같은 자리(같은 번호·같은 데이터)로 이어진다. 방장 명단이 2명에서 늘지 않는다.
- **사설 호스트(Steam, 두 컴퓨터·두 계정, App ID 480)**: 한쪽에서 `GameNet.CreateRoom(4)` → `GameNet.InviteToRoom()`으로 친구 초대 → 다른 쪽이 Steam 친구 목록에서 참가 → 방장에게 접속(명단 2명). 방장이 나가면 다른 쪽에 "서버 연결이 끝났습니다" 알림.

## 3. Unity 안에서만 도는 시험(버튼 한 번)

- Window › General › Test Runner › EditMode › Run All: 전체 통과, 도는 동안·끝난 뒤 콘솔에 `[MomoiProject]` 경고가 없다(테스트용 형식의 경고는 나오지 않는다). 에디터 전용 시험(DB 목록·저장·ID 바꾸기·다이얼로그 진행·테스트 상황·[ShowIf] 숨김 등)은 오프라인으로 돌릴 수 없어 이것만 남긴다.
